RÉPARTI — Guide de mise en ligne

Ce guide t'accompagne pas à pas pour rendre RÉPARTI disponible sur ton ordinateur, ta tablette et ton téléphone, avec un compte et une synchronisation automatique. Compte environ 30 minutes, une seule fois. Aucune ligne de code à écrire.

🗺️ Vue d'ensemble

ServiceÀ quoi il sertCe que tu y mets
SupabaseStocke les comptes et les données, envoie les codes de connexionLe contenu du fichier supabase-reparti.sql + 2 modèles d'e-mail
GitHubRange les fichiers de l'applicationTous les fichiers du dossier reparti-app (et tes 2 informations Supabase dans config.js)
NetlifyMet l'application en ligne à une adresse web, et la met à jour toute seule quand GitHub changeRien à téléverser : tu le relies à GitHub

Ordre à suivre : ① Supabase → ② GitHub → ③ Netlify → ④ installation sur tes appareils.

Contenu du dossier reparti-app (décompresse d'abord le fichier .zip : clic droit → Extraire tout sur Windows, double-clic sur Mac) :

  • reparti.html — l'application elle-même
  • index.html — la page d'accueil qui ouvre l'application
  • config.js — où tu colleras tes 2 informations Supabase
  • manifest.webmanifest, sw.js, dossier icons — ce qui rend l'application installable et utilisable hors connexion
  • netlify.toml — les réglages pour Netlify
  • supabase-reparti.sql — le script pour Supabase
  • README.md, .nojekyll — informations techniques (à mettre sur GitHub aussi, sans y toucher)
Les 2 seules informations à copier d'un service à l'autreLe Project URL et la clé anon public de Supabase. Garde un bloc-notes ouvert pour les coller au fur et à mesure.

1 Supabase — les comptes et les données

Durée : 10 minutes. Gratuit.

1.1 Créer ton compte

  1. Va sur supabase.com et clique sur Start your project.
  2. Choisis Continue with GitHub si tu as déjà un compte GitHub (le plus simple), sinon inscris-toi avec ton e-mail et confirme-le.
Tu as déjà un projet Supabase pour Taskflow ?Tu peux le réutiliser : ouvre-le et passe directement à l'étape 1.3. Les tables de RÉPARTI et de Taskflow ne se mélangent pas.

1.2 Créer le projet

  1. Clique sur New project (choisis ton organisation si on te le demande).
  2. Project name : reparti
  3. Database Password : clique sur Generate a password et note-le dans un endroit sûr (tu n'en auras pas besoin pour RÉPARTI, mais il ne faut pas le perdre).
  4. Region : West EU (Paris) ou Central EU (Frankfurt) — les plus proches de l'Afrique de l'Ouest.
  5. Clique sur Create new project et patiente 1 à 2 minutes pendant la préparation.

1.3 Créer la table de RÉPARTI

  1. Dans le menu de gauche, clique sur SQL Editor (icône >_).
  2. Clique sur + New query (ou New SQL snippet).
  3. Ouvre le fichier supabase-reparti.sql avec le Bloc-notes (clic droit → Ouvrir avec → Bloc-notes ; sur Mac : TextEdit), sélectionne tout (Ctrl+A / ⌘+A), copie, puis colle dans Supabase.
  4. Clique sur Run (en bas à droite). Résultat attendu : « Success. No rows returned ».
  5. Vérification : menu Table Editor → tu dois voir une table reparti_data.
Si Supabase affiche un avertissement « destructive operation »C'est normal (le script supprime puis recrée ses propres règles de sécurité). Clique sur Run this query.

1.4 Faire envoyer un code à 6 chiffres par e-mail

Par défaut Supabase envoie un lien ; RÉPARTI utilise un code, plus pratique sur une application installée.

  1. Menu Authentication → Emails (ou Email Templates), onglet Templates.
  2. Ouvre le modèle Magic Link :
    • Subject : Ton code RÉPARTI
    • Message body : efface tout et colle :
    <h2>Ton code RÉPARTI</h2>
<p>Voici ton code de connexion :</p>
<p style="font-size:28px;font-weight:bold;letter-spacing:4px">{{ .Token }}</p>
<p>Il est valable quelques minutes. Si tu n'as rien demandé, ignore cet e-mail.</p>
    Clique sur Save changes.
  3. Ouvre le modèle Confirm signup (envoyé lors de la toute première connexion) et fais exactement la même chose (même objet, même message), puis Save changes.
Vérifieque le message contient bien {{ .Token }} avec les doubles accolades : c'est ce qui sera remplacé par le code.

1.5 Récupérer tes 2 informations

  1. Clique sur la roue dentée Project Settings (en bas du menu de gauche).
  2. Va dans Data API (ou API) : copie le Project URL (forme https://abcdefghij.supabase.co) dans ton bloc-notes.
  3. Va dans API Keys : copie la clé anon public (une longue suite qui commence souvent par eyJ). Si tu vois aussi une publishable key (sb_publishable_…), l'une ou l'autre fonctionne.
⚠️ Ne copie jamais la clé « service_role » (ou « secret »)Elle donne tous les droits sur ta base. Seule la clé anon public va dans RÉPARTI : elle est faite pour être visible, la sécurité est assurée par les règles créées à l'étape 1.3.

1.6 (Optionnel) Connexion par numéro de téléphone

L'envoi de SMS est payant et nécessite un fournisseur. À faire plus tard si tu le souhaites :

  1. Crée un compte chez Twilio (ou MessageBird, Vonage) et achète un numéro d'envoi.
  2. Supabase → Authentication → Sign In / Providers → Phone → active-le, choisis le fournisseur et colle ses identifiants.
  3. Dans config.js sur GitHub (voir 2.4), remplace phoneLogin: false par phoneLogin: true.

2 GitHub — ranger les fichiers

Durée : 10 minutes. Gratuit.

2.1 Se connecter

Va sur github.com et connecte-toi (tu as déjà le compte adjaratou356-beep).

2.2 Créer le dépôt

  1. Va sur github.com/new.
  2. Repository name : reparti
  3. Description (facultatif) : Ton argent. Tes règles. Chaque franc à sa place.
  4. Choisis Public ou Private : les deux fonctionnent avec Netlify. Private est conseillé si tu ne veux pas que le code soit visible. Tes données personnelles ne sont jamais dans GitHub de toute façon.
  5. Ne coche rien d'autre (pas de README, pas de .gitignore, pas de licence).
  6. Clique sur Create repository.

2.3 Téléverser les fichiers

  1. Sur la page du dépôt vide, clique sur le lien uploading an existing file (dans la phrase « Get started by creating a new file or uploading an existing file »).
  2. Ouvre le dossier reparti-app sur ton ordinateur, sélectionne tout son contenu (Ctrl+A / ⌘+A) — y compris le dossier icons — et fais-le glisser dans la zone de dépôt de GitHub.
    Le fichier .nojekyll est invisible sur certains ordinateurs : ce n'est pas grave s'il manque.
  3. Attends que tous les fichiers apparaissent dans la liste (une dizaine), puis en bas clique sur Commit changes.
  4. Vérifie : la page du dépôt affiche reparti.html, index.html, config.js, le dossier icons (avec 4 images), etc.
Le dossier icons n'apparaît pas ?Certains navigateurs n'envoient pas les dossiers. Clique sur Add file → Upload files, puis glisse le dossier icons lui-même (pas son contenu) avec Chrome ou Edge, et Commit changes.

2.4 Coller tes informations Supabase dans config.js

  1. Dans le dépôt, clique sur le fichier config.js.
  2. Clique sur l'icône crayon ✏️ (Edit this file) en haut à droite du fichier.
  3. Remplace COLLE_ICI_TON_PROJECT_URL par ton Project URL, et COLLE_ICI_TA_CLE_ANON_PUBLIC par ta clé anon. Garde les guillemets. Le résultat doit ressembler à : 
    window.REPARTI_CONFIG = {
  supabaseUrl: "https://abcdefghij.supabase.co",
  supabaseAnonKey: "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJpc3Mi...",
  phoneLogin: false
};
  4. Clique sur Commit changes… puis de nouveau Commit changes dans la fenêtre.

3 Netlify — mettre en ligne

Durée : 5 minutes. Gratuit.

3.1 Créer ton compte

  1. Va sur app.netlify.com/signup.
  2. Clique sur Sign up with GitHub et autorise Netlify. Réponds aux quelques questions d'accueil (usage personnel).

3.2 Relier ton dépôt GitHub

  1. Dans Netlify, clique sur Add new project (ou Add new site) → Import an existing project.
  2. Choisis GitHub. Si une fenêtre GitHub s'ouvre, clique sur Authorize Netlify, puis à la question « Where do you want to install Netlify? » choisis ton compte, sélectionne Only select repositories → reparti → Install.
  3. De retour dans Netlify, clique sur le dépôt reparti.
  4. Réglages de publication :
    • Branch to deploy : main
    • Base directory : laisser vide
    • Build command : laisser vide
    • Publish directory : laisser vide (ou .)
  5. Clique sur Deploy reparti (ou Deploy site). Au bout de 10 à 30 secondes, le statut passe à Published.

3.3 Choisir ton adresse

  1. Netlify t'a donné une adresse au hasard (ex. jolly-cat-123.netlify.app).
  2. Va dans Project configuration (ou Site configuration) → General → Change project name (ou Change site name).
  3. Tape par exemple reparti-adjaratou et enregistre. Ton adresse devient https://reparti-adjaratou.netlify.app.

3.4 Tester

  1. Ouvre ton adresse dans le navigateur.
  2. Sur l'écran de bienvenue, clique sur Se connecter / créer un compte, tape ton e-mail, puis Recevoir mon code.
  3. Ouvre ta boîte mail (regarde aussi les spams), recopie le code à 6 chiffres et valide.
  4. Termine l'accueil (revenus, comptes, lignes, objectifs, répartition). En bas du menu (sur ordinateur) ou dans Paramètres, tu dois lire « ☁️ Synchronisé · ton-e-mail ».
Bonne nouvelle pour les mises à jourChaque fois que tu modifies un fichier sur GitHub, Netlify republie l'application automatiquement en moins d'une minute.

4 Installer RÉPARTI sur tes appareils

À faire sur chaque appareil, avec ton adresse Netlify. Puis connecte-toi avec le même e-mail : tes données apparaissent automatiquement.

AppareilComment faire
💻 Ordinateur
Chrome ou Edge		Ouvre l'adresse → clique sur l'icône Installer (écran avec une flèche ⬇️) à droite de la barre d'adresse, ou menu ⋮ → Installer RÉPARTI (Edge : … → Applications → Installer) → Installer. Sur Mac avec Safari : Fichier → Ajouter au Dock.
📱 AndroidOuvre l'adresse dans Chrome → ⋮ en haut à droite → Installer l'application (ou Ajouter à l'écran d'accueil) → Installer.
📱 iPhoneOuvre l'adresse dans Safari → bouton Partager (carré avec une flèche ⬆️) → Sur l'écran d'accueil → Ajouter.
📲 iPadComme l'iPhone (Safari → Partager → Sur l'écran d'accueil).
📲 Tablette AndroidComme Android (Chrome → ⋮ → Installer l'application).

Ensuite, ouvre RÉPARTI depuis son icône → Se connecter / créer un compte → même e-mail → code. C'est tout : chaque modification est envoyée à tes autres appareils (à l'ouverture de l'application, après chaque saisie et toutes les minutes).

🔄 Faire une mise à jour plus tard

  1. Quand je t'envoie une nouvelle version de reparti.html (ou d'un autre fichier), va dans ton dépôt GitHub reparti.
  2. Add file → Upload files → glisse le ou les nouveaux fichiers → Commit changes. GitHub remplace les anciens.
  3. Ne remplace pas config.js (sinon tu perds tes informations Supabase), sauf si je te le demande.
  4. Netlify republie tout seul. Sur tes appareils, ferme puis rouvre RÉPARTI (deux fois si besoin) pour recevoir la nouvelle version. Tes données ne sont pas touchées.

🛟 Si quelque chose ne marche pas

Ce que tu voisSolution
Le bouton « Se connecter » n'apparaît pasconfig.js n'est pas rempli ou mal rempli : vérifie les guillemets et qu'il ne reste pas COLLE_ICI. Attends 1 minute puis recharge la page.
Le code n'arrive pasRegarde dans les spams. L'offre gratuite de Supabase limite le nombre d'e-mails par heure : patiente quelques minutes et redemande un code. Pour beaucoup d'utilisateurs, il faudra brancher un service d'envoi (ex. Resend) dans Authentication → Emails → SMTP Settings.
L'e-mail contient un lien mais pas de codeRefais l'étape 1.4 : le message doit contenir {{ .Token }}, dans Magic Link et dans Confirm signup.
« Code incorrect ou expiré »Utilise le dernier code reçu, rapidement après l'avoir demandé.
« ⚠️ Synchronisation en attente »Vérifie que le script de l'étape 1.3 a bien été exécuté (table reparti_data présente). Vérifie ta connexion internet.
Supabase dit « Project paused »Un projet gratuit se met en pause après 7 jours sans utilisation : ouvre le projet dans Supabase et clique sur Restore project. Avec un usage régulier, ça n'arrive pas.
Pas de bouton « Installer » sur l'ordinateurUtilise Chrome ou Edge (pas Firefox), et l'adresse Netlify en https://. L'application est peut-être déjà installée.
Netlify affiche « Page not found »Vérifie que index.html et reparti.html sont à la racine du dépôt GitHub (pas dans un sous-dossier). Sinon, déplace-les ou mets ce sous-dossier dans Publish directory.
